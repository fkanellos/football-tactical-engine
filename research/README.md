# research

Colab-ready Jupyter notebooks for computer vision and machine learning experimentation.

This is where we prototype the perception layer of the pipeline: player/ball detection,
tracking, camera calibration, pitch homography, and jersey/team classification. Notebooks
here are meant to be opened directly in Google Colab (each starts with environment setup
cells) so experiments don't depend on local hardware or a fixed local environment.

Findings that are worth keeping around long-term (architecture decisions, benchmark
results, model comparisons) should be written up in `/docs` rather than left buried in a
notebook.
